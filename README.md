# Копилка

Мобильный сайт по твоему макету: тёмный фон, цветные копилки и твоя золотая монетка. Работает без библиотек, сборки, регистрации и внешних сервисов.

## Как запустить на компьютере

Нужен Node.js 18 или новее (на этом компьютере уже установлен).

Открой PowerShell в папке проекта и выполни:

```powershell
cd C:\Users\kuravella\Desktop\kopilka
npm.cmd start
```

Открой **http://localhost:5173** в браузере. Устанавливать пакеты через `npm install` не нужно. Альтернативная команда запуска: `node server.mjs`.

Для остановки нажми **Ctrl+C** в терминале. После изменения файлов обнови страницу браузера.

Если порт занят, выбери другой:

```powershell
$env:PORT = 5174
npm.cmd start
```

## Как проверить на телефоне

1. Подключи телефон и компьютер к одной сети Wi-Fi.
2. Запусти сайт на компьютере командой выше и оставь терминал открытым.
3. В терминале появится адрес «В локальной сети», например `http://192.168.1.10:5173`.
4. Открой **именно этот адрес** в браузере телефона. `localhost` на телефоне указывает на сам телефон.
5. Если Windows спросит доступ для Node.js, разреши его для **частной сети**. Если адресов несколько, используй IPv4 своего Wi-Fi-адаптера (его можно посмотреть командой `ipconfig`).

Номер порта в адресе должен совпадать с портом, на котором запущен сервер.

## Что можно делать

- Нажать на любую копилку: изменить название, сумму и цвет.
- Кнопками `−1 000 ₽` и `+1 000 ₽` в окне менять сумму перед сохранением.
- Верхней кнопкой `+1 000` выбрать копилку и сразу добавить в неё монетку.
- Нажать `+` вверху или пустой квадрат: создать копилку.
- Удалить копилку через её окно с подтверждением.
- В настройках скачать резервную копию JSON или восстановить её. Перед заменой данных сайт спросит подтверждение.

Одна целая монетка соответствует **1 000 ₽**. Остаток меньше тысячи отображается частью монетки. Если монет очень много, в квадрате показаны первые 30, а число `+…` показывает остальные, включая неполную монетку. Точная сумма всегда видна под квадратом.

Суммы группируются пробелами: `10 000 ₽`, `1 234 567,89 ₽`. Можно вводить пробелы, запятую или точку для копеек. Внутри программы суммы хранятся целыми копейками. Лимит одной копилки — `99 999 999 999,99 ₽`, количество копилок — до 100.

При первом открытии копилок нет, общая сумма — `0 ₽`. Нажми на квадрат с плюсом, чтобы создать первую копилку. Созданные пользователем копилки сохраняются после перезагрузки.

## Как выложить на GitHub и открыть сайт по ссылке

1. На GitHub создай новый публичный репозиторий, например `kopilka`.
2. Через **Add file → Upload files** загрузи содержимое папки проекта, включая папку `assets`, и нажми **Commit changes**. Файл `index.html` должен находиться в корне репозитория.
3. Чтобы сайт открывался по ссылке, зайди в **Settings → Pages**, выбери **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
4. Дождись публикации: ссылка появится в этом же разделе. Обычно адрес имеет вид `https://ТВОЙ-ЛОГИН.github.io/kopilka/`.

Для GitHub Pages сборка и запуск Node.js не нужны: сайт работает как набор статических файлов. Данные копилок хранятся в браузерах посетителей.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Где хранятся данные

Автоматически в `localStorage` браузера. Они сохраняются после обновления страницы и перезапуска сервера. Данные привязаны к браузеру, устройству и адресу сайта: у `localhost`, IP-адреса компьютера и другого порта отдельные хранилища. Между компьютером и телефоном переноси данные через резервную копию в настройках.

При очистке данных браузера копилки удаляются. Регулярно скачивай резервную копию. Сайт ведёт учёт сумм, банковские операции не выполняет.

## Файлы

```text
kopilka/
├── assets/
│   ├── coin.png     — твой исходный спрайт монетки
│   └── icon.svg     — иконка вкладки
├── index.html       — страница и окна
├── styles.css       — мобильная вёрстка
├── app.js           — копилки, суммы, сохранение и резервные копии
├── server.mjs       — локальный сервер на Node.js
├── package.json     — команда npm start
└── README.md        — эта инструкция
```

Монетка используется из исходного PNG: чёрное поле вокруг неё обрезается только средствами CSS, оригинал сохранён без изменений. Внешние шрифты и картинки не загружаются.
